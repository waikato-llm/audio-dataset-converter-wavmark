# audio-dataset-converter-wavmark
The **audio-dataset-converter-wavmark** library is an extension to **audio-dataset-converter** 
integrating the [WavMark](https://github.com/wavmark/wavmark) library for watermarking audio files.

A GPU device is recommended to speed up processing.

## Installation

Via PyPI:

```bash
pip install audio_dataset_converter_wavmark
```

The latest code straight from the repository:

```bash
pip install git+https://github.com/waikato-llm/audio-dataset-converter-wavmark.git
```
